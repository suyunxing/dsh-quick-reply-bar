# 快捷回复条

输入框上方的一个小按钮，点开就是一排短语，点一下直接把短语发出去。

## 用法

| 操作 | 效果 |
| --- | --- |
| 收起时点「快捷回复」小按钮 | 展开成一横排短语按钮 |
| 点任意短语按钮 | 立刻把这段文字发送出去（不是插入草稿） |
| 点最左边的折角按钮 | 收回到一个小按钮 |
| 点最右边的 ＋ | 进入编辑面板，改完点「完成」 |
| 编辑面板里 ↑ ↓ | 调整按钮顺序 |
| 编辑面板里 × | 删除这一条 |
| 编辑面板里「添加一条」 | 新增一条空白短语 |
| 编辑面板里「恢复默认」 | 回到内置的 4 条示例 |

## 编辑

每条短语有两栏：

- **按钮上显示的字**：留空时自动用内容开头的十来个字当按钮名。
- **要发送的内容**：点按钮时原样发出去，可以多行。

内容为空的条目不会出现在按钮条上（但仍留在编辑面板里，方便慢慢写）。

## 存哪里

- 短语：浏览器 `localStorage`，键 `dsh-quick-reply-bar:v1`。
- 展开/收起状态：`dsh-quick-reply-bar:ui:v1`。

所以它跟浏览器 profile 走，不写配置文件。换浏览器、清站点数据会回到默认的 4 条。

## 细节

- 最多 60 条，单条内容最多 4000 字。
- 发送时会把你原本写了一半的草稿暂存，发完自动放回去。
- 输入框正在忙（上一次还没发完）时按钮变灰，避免连点。
- 颜色全部取自主题变量，浅色/深色都跟随。
